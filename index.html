Process

How an automation actually gets built.

The same five steps behind Hayes & Ride's booking assistant, repeated for every project that needs one.

01

Map the real conversation

Before any code, I write out what a customer actually says and what has to happen in response — the workflow gets designed around that, not the other way around.

02

Design the workflow in n8n

Each step in the conversation becomes a node: check availability, validate details, write to the database, trigger a confirmation.

03

Connect the real systems

The workflow talks to the actual product APIs and database — not a mock — so what it books is what shows up in the app.

04

Give it a voice or a chat window

An AI-backed agent sits in front of the workflow, handling the call or chat and passing structured requests down the pipeline.

05

Ship it and watch it run

Deployed, then watched against real usage for a while — edge cases in a live conversation show up fast, and the workflow gets tightened from there.
